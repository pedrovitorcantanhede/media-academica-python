# Calculadora de Média Acadêmica em Python

Projeto simples desenvolvido em Python para calcular a média de três notas e informar a situação acadêmica do aluno.

## Funcionalidades

- Recebe três notas do usuário
- Valida se cada nota está entre 0 e 10
- Calcula a média
- Informa a situação:
  - Aprovado
  - Recuperação
  - Reprovado

## Conceitos utilizados

- Variáveis
- Entrada e saída de dados
- Listas
- Estrutura de repetição `while`
- Estruturas condicionais `if`, `elif` e `else`
- Operadores lógicos
- Funções nativas como `sum()` e `len()`

## Exemplo de execução

```text
=== Calculadora de Média Acadêmica ===

Digite a 1ª nota: 8
Digite a 2ª nota: 6
Digite a 3ª nota: 7

Média: 7.00
Situação: Aprovado
